# 🌾 Agriculture AI Chatbot

An intelligent AI-powered chatbot that helps users with agriculture-related queries such as crop advice, irrigation guidance, soil information, pest control, and weather-based farming suggestions.

## 🚀 Features
- Crop recommendations
- Irrigation advice
- Soil and fertilizer guidance
- Pest control support
- Responsive chat UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
